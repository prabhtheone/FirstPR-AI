Run it on your machine

Choose cloud AI or your own local model.

The hosted demo uses a cloud AI endpoint. You can still run FirstPR AI locally with Python, Gradio, and Ollama; local mode does not need a cloud API key.

1
Install the prerequisites

Install Python 3.10+, Git, and Ollama.

2
Clone and install

Run these commands in PowerShell.

3
Download the model and launch

Open the local interface in your browser.

git clone https://github.com/prabhtheone/FirstPR-AI.git
cd FirstPR-AI
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
ollama pull llama3.2:3b
python app.py

Then open http://127.0.0.1:7860. Keep Ollama running while using the app. If PowerShell blocks virtual-environment activation, use .venv\Scripts\python.exe -m pip install -r requirements.txt and .venv\Scripts\python.exe app.py.

Privacy note
Cloud mode sends prompts to the configured AI provider for processing. For sensitive or confidential material, use the local Ollama app instead. Never paste passwords, tokens, or private keys.
