Run it on your machine

Your model. Your machine.

FirstPR AI uses Python, Gradio, and Ollama. After you download the model once, you can run the AI locally without a cloud AI API key.

1
Install the prerequisites

Install Python 3.10+, Git, and Ollama.

2
Clone and install

Run these commands in PowerShell.

3
Download the model and launch

Open the local interface in your browser.

git clone https://github.com/prabhtheone/FirstPR-AI.git
cd FirstPR-AI
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
ollama pull llama3.2:3b
python app.py

Then open http://127.0.0.1:7860. Keep Ollama running while using the app. If PowerShell blocks virtual-environment activation, use .venv\Scripts\python.exe -m pip install -r requirements.txt and .venv\Scripts\python.exe app.py.

Privacy by design
In the current local app, prompts are sent to the Ollama service on your computer. Review AI output before acting on it, and never paste passwords, tokens, private keys, or confidential information.
